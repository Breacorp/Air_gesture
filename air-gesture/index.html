WEBAPP INSTALABLE · PWA

Instalala en tu equipo

La misma aplicación web se puede instalar desde navegadores compatibles. No hay instaladores nativos publicados para macOS o Windows.

Si tu navegador ofrece instalación, usá la opción «Instalar aplicación» de su menú.

Descarga localmente los modelos y recursos de seguimiento (aprox. 50 MB).

Requisitos: navegador con soporte para cámara, acceso por HTTPS (o localhost) y cámara web. La instalación como PWA depende del navegador. El seguimiento de manos, cuerpo y rostro usa modelos locales. El control global del escritorio requiere además el puente nativo disponible para macOS.

06 / PREGUNTAS FRECUENTES

Lo esencial, sin letra chica.

¿Necesito crear una cuenta?

No. Esta versión no incluye cuentas ni inicio de sesión.

¿Puedo usar Air Gesture sin conexión?

Sí. La primera visita y preparación necesitan conexión para descargar la aplicación y alrededor de 50 MB de modelos y recursos. Después, la app instalada puede funcionar sin conexión: cámara, seguimiento y demás procesamiento ocurren en este equipo, sin solicitudes a Vercel. El almacenamiento del navegador puede eliminarse desde sus ajustes.

¿Se envía el video de mi cámara?

El seguimiento utiliza MediaPipe y recursos locales; las imágenes de cámara se procesan en el equipo y no se envían a un servicio de Air Gesture. La cámara solo se solicita cuando iniciás la experiencia.

¿Hay una descarga nativa para macOS o Windows?

Aún no hay instaladores nativos publicados. En navegadores compatibles podés instalar la PWA; es la aplicación web guardada por el navegador, no un paquete nativo independiente.

¿Qué sistema operativo es compatible?

La aplicación web requiere un navegador con cámara, WebGL y soporte para las tecnologías web usadas por MediaPipe. La instalación PWA varía según navegador y sistema operativo; todavía no se publica una matriz de compatibilidad certificada. El puente de control global está disponible para macOS.

¿Qué hace falta para controlar todo el escritorio?

El puntero y las experiencias dentro de Air Gesture funcionan en la aplicación web. Las acciones globales del escritorio requieren el puente nativo de macOS y sus permisos del sistema.
